## Package: `npm run pack:ext`
`package.json` script: build the extension, then `node scripts/pack-extension.mjs`, which writes
`dist/aprende-extension.zip` from `dist/extension` with `manifest.json` at the root and **without** `.vite/`, `*.map`
and any `src/`. Use `node:zlib` (deflate) or one small free devDependency (e.g. `fflate`); no `zip` binary (not on
every machine). Keep `dist/extension/.vite/manifest.json` on disk: the T8-01 test reads it.

## Static check: `node scripts/check-extension.mjs <zip|dir>`
Prints one line per problem, `FAIL <file>: <rule>`, then exits 1; prints `ok` and exits 0 when clean. Rules:
1. `manifest.json` at the root; `manifest_version` 3; `name` 1–75 chars; `description` 1–132 chars; `version` is 1–4
   dot-separated integers.
2. Every file the manifest names exists (`background.service_worker`, `side_panel.default_path`,
   `action.default_popup`, every icon); icons are PNG with the declared pixel size.
3. No remote code: in `*.html`, no `<script src=` with `http:`/`https:`/`//`; in `*.js`, no `import("http…")`/
   `import('//…')`, no `importScripts(` with a remote URL, no `eval(`, no `new Function(`. Name the file.
4. CSP `extension_pages`: `script-src` is exactly `'self'` (no `unsafe-eval`, `unsafe-inline`, `wasm-unsafe-eval` or
   hosts); `object-src 'self'`.
5. Storage: any `storage.local` / `storage.sync` / `storage['local']` / `storage["sync"]` in any `*.js` fails, naming
   the file and `storage.local` or `storage.sync` (only `chrome.storage.session` is allowed, design D10).
6. Permissions: every entry in `permissions` must be used: `chrome.<name>` appears in some `*.js` (`sidePanel`,
   `storage`, …); an unknown or unused one fails, naming it.
7. Hosts: exactly one `host_permissions` entry, `https://…/*`, and that origin appears in the JS (the API origin is
   built in). A second host fails, naming it.
No network access. The check is the "equivalent" of the Store's static review the backlog asks for (no account, free).
Add a CI step in `.github/workflows/ci.yml` job `frontend`, after "build extension": `npm run pack:ext && node
scripts/check-extension.mjs dist/aprende-extension.zip`, and upload the zip as an artifact (`actions/upload-artifact`).
