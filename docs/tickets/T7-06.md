Written by the Opus test writer (t7-tests) on 2026-11-20. Branch `feat/t7-06-analytics` from `origin/main`. The

## Goal
Spec 12: analytics events with no client content (no names, no answers, no free text, no IP addresses), and a staff
dashboard (spec 11 "Analítica"): lesson completion, drop-off by item, quiz accuracy per item, conversion to paid, and
on-time completion of the 14 days.

## Analytics sinks (what "no client content" covers)
- the `events` table (analytics; today only `learn.submit_attempt` writes `item_answered`),
- `ai_calls` (hashes and counts only, T2-08),
- staff phone alerts (`notify.notify_staff`, logged when no ntfy topic is set) and the server logs/stdout.
`journey_events`, `datos_answers`, `conflict_checks` etc. are the client's file, not analytics, and are out of scope.

## One writer: new `backend/aprende/analytics.py`
```python
EVENTS = {                                   # type -> allowed prop keys (spec 12), nothing else
  "lesson_started": {"lesson_id"}, "item_answered": {"item_id", "correct", "attempt"}, "lesson_completed": {"lesson_id"},
  "datos_question_answered": {"question_id", "skipped"}, "datos_completed": set(),
  "consent": {"answer"}, "conflict_auto": {"result"}, "documents_tentative": {"codes"},
  "engagement_signed": set(), "checkout_started": set(), "paid": set(), "drafts_ready": set(),
  "attorney_approved": set(), "client_confirmed": set(), "changes_requested": set(), "signing_booked": set(),
  "signed": set(), "final_lesson_completed": set(), "step_late": {"step"},
}
def record(journey_id: str, type_: str, props: dict | None = None, *, conn=None) -> None
```
- Unknown type, or a prop key not in `EVENTS[type_]` → `ValueError`. Values must be `bool`, `int`, a string of at most
  40 characters matching `^[a-z0-9_.:-]*$`, or a list of such strings; anything else → `ValueError`.
- Every row also gets `props["day"]` = the journey's day (`journey.get_journey(jid)["day"]`) and `target` =
  `"extension"` when the current request's `Origin` starts with `chrome-extension://`, else `"web"` (read through a
  `contextvars.ContextVar` set by one small middleware in `app.py`; outside a request: `"web"`).
- `conn` = write inside the caller's transaction (as `learn.submit_attempt` does today).
- Replace the direct `INSERT INTO events` in `learn.py` with `record`. No other code writes `events`.

## Dashboard: `GET /staff/analytics?since=<ISO date or datetime>` (staff: paralegal, attorney, admin)
Counts only journeys with `journeys.started_at >= since` (all journeys without `since`); every count is distinct
journeys; a rate is `round(n / d, 3)`, or `null` when `d == 0`.
```json
{"lessons": [{"lesson_id", "started", "completed", "completion_rate", "dropped_before_first_item"}],
 "items":   [{"item_id", "lesson_id", "answered", "first_try_correct", "accuracy", "drop_off"}],
 "conversion": {"journeys", "paid", "rate"},
 "on_time":    {"finished", "on_time", "rate"}}
```
- `started` = journeys with `lesson_started`; `completed` = with `lesson_completed` for that lesson.
- `answered` = journeys with an `item_answered` attempt 1 for the item; `first_try_correct` = of those, correct;
  `accuracy` = `first_try_correct / answered`.
- `drop_off` (item) = journeys that started the lesson, did not complete it, and whose latest `item_answered` in that
  lesson is this item. `dropped_before_first_item` = started, not completed, no `item_answered` in it.
- `conversion`: `journeys` = journeys counted; `paid` = with the `paid` fact.
- `on_time`: `finished` = with `final_lesson_completed`; `on_time` = finished with **no** `timeline_alerts` row (no firm
  step went late). Assumption until Q-W1 (the 14-day promise) is answered; record it in `docs/aprende-decisions.md`.
- Lessons in `content_lessons.position` order; items in step/item order; only lessons/items with events.
Reads `events`, `journeys`, `journey_events` (facts), `timeline_alerts` only. No names anywhere in the response.

## Admin (part b): `web/admin.html` `<section id="analitica">` heading "Analítica" + `web/analytics.js`
Three tables from `GET /staff/analytics`: "Lecciones" (Lección, Empezaron, Terminaron, % terminaron, Dejaron antes de
empezar), "Preguntas" (Pregunta, Respondieron, Acertaron a la primera, % acierto, Dejaron aquí), and two lines
"Pagaron: P de J (R %)" and "Terminaron a tiempo: T de F (R %)" (R = rate × 100, rounded to a whole number); a `null`
rate shows "—". In the item table "Dejaron aquí" is the last column. Text nodes only.
