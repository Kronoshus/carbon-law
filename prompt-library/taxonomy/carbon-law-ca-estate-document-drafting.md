# California Estate Document Drafting Taxonomy — Carbon Law Project Scope

Scope is limited to four drafts already selected in the Carbon Law workflow. These are four separate prompt specifications, not a full California estate-planning taxonomy.

## Trust instrument working draft
**Revocable Living Trust Drafting Prompt** — Use only provided intake and the existing trust summary template; organize a proposed trust draft with unresolved provisions isolated for attorney completion. California Probate Code §§ 15200, 15400 are research anchors, not a determination of validity.

## Pour-over will working draft
**Pour-Over Will Drafting Prompt** — Prepare a proposed will-shaped attorney-review draft from provided nominations and trust reference; disclose missing terms and do not claim validity. Research anchors: Probate Code §§ 6110–6111, 6300–6303.

## Health care directive working draft
**Advance Health Care Directive Drafting Prompt** — Organize the provided agent, alternate, and expressed instructions into a draft for attorney review; do not add medical choices or infer authority. Research anchors: Probate Code §§ 4670–4675, 4701.

## Financial power of attorney working draft
**Financial Power of Attorney Drafting Prompt** — Organize named agents and expressly provided scope into a proposed draft; flag missing statutory-form selections, special powers, and execution details. Research anchors: Probate Code §§ 4121–4122, 4401.

## Shared boundaries
All four outputs are attorney-review work product only; never certify legal sufficiency, execution, funding, or approval. Refuse to infer material choices. No sub-state variation is modeled in this limited prompt set; if a county, property, or execution location matters, flag it for attorney review rather than infer local rules.
