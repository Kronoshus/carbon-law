# California Estate Planning Matter Stage Model

Every matter has exactly one current stage. When work moves, the stage changes in the tracker on the same day.

| Stage | Goal | Exit criteria |
|---|---|---|
| 1 Intake | Capture parties, conflict check, scope, engagement terms | Conflict cleared, scope approved |
| 2 Attorney Scope | Attorney confirms plan type and strategy | Strategy documented |
| 3 Client Data Collection | Full questionnaire, assets, debts, property title | Data complete |
| 4 Drafting | Create trust, wills, POAs, HIPAA, deed | First draft created |
| 5 Review Queue | Attorney reviews draft | Attorney comments resolved |
| 6 Client Review | Client reviews drafts and confirms changes | Client approval or change list |
| 7 Signing Preparation | Scheduling, witnesses, notary, funding guide | Signing appointment confirmed |
| 8 Execution | Documents signed and notarized | Executed documents scanned |
| 9 Funding Follow-Up | Assets moved or instructions delivered | Funding checklist complete |
| 10 Closed | Final delivery and follow-up | Matter closed in system |

## Change request triggers
- New child or dependent
- New marriage or divorce
- New property
- New accounts or business
- Change in fiduciary
- Change in distribution
- Beneficiary death or incapacity
- Client instruction change
