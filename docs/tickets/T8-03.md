# T8-03 · Installable PWA and push reminders — builder brief

Written by the Opus test writer (p8-tests) on 2026-11-20. Branch `feat/t8-03-pwa-reminders`. The acceptance tests are on
the branch; make them pass without editing them. Size L: parts a–c below, each ≤ 300 lines.

## Goal
The web app installs as a PWA; a service worker keeps the app shell and published lessons only; the Perfil tab (today
"Próximamente") gets language, the daily reminder, install and sign out; and the server sends three reminders:
1. the **daily lesson nudge** (T4-06 chose who is due; nothing sends it yet): push only, at most one a day;
2. the **appointment reminder** 24 hours before a booking (T6-07 sends only the confirmation): email always, push if
   she turned reminders on;
3. the **yearly review reminder** a year after staff record `funding_done`, then every year (T6-08 research additions):
   email, push if on, one staff alert with no name.
Spec 4.1 (Perfil), 7.4 (reminders), design D13, brief 2.1. Guides: `install-web-app`, `performance` (service workers),
`privacy`. Decision PRs: #52 (privacy: no client data cached, no names in alerts), #54 (hosting: `carbon.bailment.tech/aprende/`).

```python
    # Only when get_reminder(journey_id)["enabled"]. Per subscription: _deliver(sub, json.dumps({"title", "body", "url"}))
    # in the subscription's lang; a 404 or 410 deletes that subscription.
def _deliver(sub: dict, data: str) -> int            # HTTP status. pywebpush (add `pywebpush` to backend/requirements.txt,
    # import it inside this function), VAPID private key env APRENDE_VAPID_PRIVATE_KEY, subject "mailto:info@carbonlaw.com".
    # No keys set: log a warning (no content) and return 0.
```

## Part b — PWA (web target only; the extension is untouched)
- `aprende/public/manifest.webmanifest`: `id: "./"`, `name: "Aprende y Planea"`, `short_name: "Aprende"`, `start_url:
  "./#/aprender"`, `scope: "./"`, `display: "standalone"`, `lang: "es"`, `theme_color` and `background_color` = the night
  surface token (`--night`), icons `icons/app-192.png`, `icons/app-512.png` (PNG, from `public/img/calavera-face.png`,
  plus one `"purpose": "maskable"` 512). Relative URLs so it works under `VITE_BASE=/aprende/`.
- `index.html`: `<link rel="manifest" href="./manifest.webmanifest">` (Vite rewrites with base) and `<meta name="theme-color">`.
- **Service worker**: `src/targets/web/sw-rules.ts` exports
  `cacheKind(req: {url, method, mode, destination}, scope: string, apiOrigin: string): 'shell' | 'lesson' | null`:
  - `shell`: GET, same origin as `scope`, and either a navigation (`mode === 'navigate'`) to exactly `scope` or
    `scope + 'index.html'`, or a `script`/`style`/`font`/`image`/`manifest` destination under `scope`, or a path under
    `scope + 'characters/'`;
  - `lesson`: GET of `<apiOrigin or scope's origin>/learn/lessons/<id>` (one path segment, any query);
  - everything else `null` (journey, datos, documents, progress, map, booking, auth, payments, chat, every write).
  `src/targets/web/sw.ts` imports only `sw-rules.ts`: on `fetch`, `null` → no `respondWith` (the browser goes to the
  network untouched); `shell` navigations network-first, other shell cache-first; `lesson` network-first with the cached
  copy when offline (cache name per kind, e.g. `aprende-shell-v1`, `aprende-lessons-v1`; delete other names on `activate`).
  `push` → `showNotification(title, {body, icon: 'img/calavera-face.png', data: {url}})`; `notificationclick` → focus or
  open `scope + url`.
  Build: in web mode add an input `sw: src/targets/web/sw.ts` emitted as `dist/web/sw.js` (no hash; keep the app entry as
  is). Dev: a small Vite plugin serves `/sw.js` from `server.transformRequest('/src/targets/web/sw.ts')` with a JS content
  type. Register from `src/targets/web/main.ts` only: `navigator.serviceWorker.register(BASE + 'sw.js', {type: 'module', scope: BASE})`.
- `tests/bundle.test.ts` must still pass with the second entry (do not edit it).

## Part c — Perfil (`src/ui/screens/Perfil.tsx`, route `/perfil`, replaces the placeholder there)
One `<h1>` `perfil.title`. In this order:
1. **Language**: `<select>` labelled `perfil.language` with "Español"/"English" → `setLang`.
2. **Daily reminder**: a switch (`<input type="checkbox" switch>`, guide `switch`) labelled `perfil.reminder`, and
   `<input type="time">` labelled `perfil.reminderTime` (default 18:00); state from `GET /progress` `reminders`.
   - Turning **on**: `PUT /progress/reminders {enabled: true, local_time}`; then, if `GET /progress/push-key` has a key and
     `PushManager` exists: `Notification.requestPermission()`; if granted, `(await navigator.serviceWorker.ready)
     .pushManager.subscribe({userVisibleOnly: true, applicationServerKey})`, then `PUT /progress/push` with
     `sub.toJSON()` + `lang`. Denied: show `perfil.reminderDenied` (the reminder stays on; no push).
   - Turning **off**: `PUT /progress/reminders {enabled: false, local_time}` (the server drops the subscriptions) and
     `(await pushManager.getSubscription())?.unsubscribe()`.
   - Changing the time while on: `PUT /progress/reminders`. While off: no request.
   - Nothing on any page calls `requestPermission` or `subscribe` except this switch turning on. Reminder push is a
     web-app feature; the extension's platform keeps no notifications (T8-02).
3. **Install** (guide `install-web-app`): a `<button>` `perfil.install`, hidden unless `Navigator.prototype.install`
   exists or a `beforeinstallprompt` event was captured (listen in `main.ts` from start, `preventDefault()`, keep it in a
   signal). Click → `navigator.install()` when available, else the saved event's `prompt()` (discard it first: single
   use, hide the button after). Success → `perfil.installed` in a `role="status"` element; `AbortError` →
   `perfil.installCancelled`. No `<install>` element yet (no browser renders it; the button covers both).
4. **Sign out**: button `top.signout` → `clearToken()`, `navigate('/entrar')`. The top bar keeps its sign-out button only
   in the bare day-1 gate (`Shell` with `bare`); in the app the only one is Perfil's.

i18n (es / en): `perfil.title` Perfil / Profile · `perfil.language` Idioma / Language · `perfil.reminder` Recordatorio
diario / Daily reminder · `perfil.reminderTime` Hora del recordatorio / Reminder time · `perfil.reminderNote` Le avisamos
