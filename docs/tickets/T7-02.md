# T7-02 · Validator in the admin — builder brief

Written by the Opus test writer (t7-tests) on 2026-11-20. Branch `feat/t7-02-validator-admin` from `origin/main`
(T7-01 merged, #71). The acceptance tests are on the branch; make them pass without editing them.

## Goal
The T4-02 validator (`content.validate`) checks every lesson item version that staff write in the admin. Its errors
appear beside the item. Submit, approve and publish are disabled in the admin with the reason in text, **and the server
refuses** to submit, approve or publish an invalid version (spec 10: "publish blocked otherwise"; T7-01 brief).

## One validator, no copy
```python
# backend/aprende/content.py
def version_errors(entry_id: str, body: dict) -> list[str]
```
- `item`: build a one-lesson bundle — the item's lesson and step from `content_lessons` / `content_steps`, this item
  with `kind`, `legal`, `sensitive`, `character` from `content_items` and `es`, `en`, `answer`, `source` from `body`
  (a key absent from `body` is absent from the item) — plus every `content_sources` row, and return the errors of
  `validate(bundle)` that contain `entry_id`. The strings are `validate`'s own; do not write new rules or messages.
- `datos`, `summary` (and later `persona`): `[]` (their rule is the two-language check T7-01 already has).

## Server
- `GET /staff/content/{entry_id}`: every element of `versions` gains `"errors": [str]` (`version_errors` of its body).
- `POST .../submit`, `.../approve`, `.../publish`: after the existing languages check (T7-01: 422 `languages` comes
  first), a version with errors → **422 `{"error": "invalid", "errors": [...]}`**; nothing changes (no state change, no
  approval row, no audit row, the live copy stays).
- `PUT .../draft` still saves an invalid draft (staff fix it step by step); its errors show in the detail.

## Admin (`web/content.js`)
- Under the fields of the shown version (the pending one, else the live one): a list `<ul class="content-errors">`
  with one `<li>` per error, preceded by the text "Errores del validador:".
- When that version has errors: "Enviar a revisión", "Aprobar versión N" and "Publicar versión N" are `disabled`, and
  the text "No se puede enviar ni publicar mientras haya errores." is shown. "Guardar borrador" stays enabled.
- No errors: no list, no text, buttons as in T7-01. Text nodes only.
