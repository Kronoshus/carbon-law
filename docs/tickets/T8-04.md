# T8-04 · Accessibility audit — builder brief

Written by the Opus test writer (p8-tests) on 2026-11-20. Branch `feat/t8-04-a11y` (from origin/main ae1d3c4). The
acceptance tests are on the branch; make them pass **by fixing the screens**, never by editing the test, excluding a rule,
an element or a state, or lowering a check. Size M; split by screen group if the diff passes 300 lines.

## Goal
WCAG 2.1 AA on every screen state, in Spanish and English (spec 13, design 10, brief 6 "Audience"); text honours the
phone's text size; nothing is lost at 320 px or at 200 % text. Guides: `accessibility`, `respect-os-text-scale`
(retrieved: `<meta name="text-scale" content="scale">`, no root font size, rem everywhere, no fixed heights on text, no
`white-space: nowrap` on sentences, wrapping grids).

## What the tests check (`aprende/e2e/a11y.spec.ts`)
- `STATES`: 31 screen states (public, the day-1 gate, map, lesson explanation / question with feedback / locked, plan,
  Preguntas ×2, Perfil, Tus datos, documents, summary, agreement ×2, payment ×2, client review, appointment ×3, signed
  documents ×2, "not available"). Each runs in **es** and **en** at 390 × 844 with axe (default rules, only `canvas`
  excluded as the existing specs do) and must have **zero violations**. A screenshot of each goes to the test output.
- Reflow at **320 × 640** and **200 % text** (Chrome's default font size set to 32 px through CDP `Page.setFontSizes`)
  for 12 key states: no sideways scroll and no visible text element outside the viewport.
- `index.html` has `<meta name="text-scale" content="scale">` and the root font size stays the browser's (16 px by default).

## Rules for fixes
- Prefer native elements (guide `accessibility`): headings, `<button>`, `<label>`, `<progress>`, `<dialog>`; ARIA only
  where HTML has nothing. Colour contrast from `tokens.css` (design 2); never fix contrast by `opacity`.
- Text sizes in rem; remove fixed `height`/`max-height` on text containers; let flex rows wrap at 320 px.
- The Perfil screen on main is still the placeholder (T8-03 builds it). Make the placeholder pass; T8-03's Perfil is
  checked again when it merges (the state list already includes it).
- Do not change copy meaning; a new or changed string goes into both `i18n/es.json` and `en.json`.
