# Carbon Law Overview

Carbon Law treats an estate planning law firm like a repeatable operations system. The goal is not to remove legal judgment. The goal is to remove wasted motion, missed handoffs, and silent status problems.

## Problems this system solves

- Missing client updates that never get incorporated into drafts.
- Draft documents with no attorney review record.
- Intake data that names only one child when the client has two.
- Unclear title/ownership information for the home.
- Clients calling twice without a useful status answer.
- Growth from 30 to 100 active matters without adding chaos.
- Last-minute changes after documents are already drafted.

## Design rules

- One matter record per matter.
- One stage field per matter.
- One next action per matter.
- One owner per task.
- Every interruption becomes a tracked change request.
- Every attorney decision is captured in writing.
- Every client-facing date is stored as a structured value.
- Every document set has a version number.
